Uma janela 3D para dados multidimensionais — entenda os limites do desenho

Esta experiência usa três dimensões para visualizar GROUP BY, ROLLUP e CUBE. No SQL, uma dimensão é um atributo de agrupamento: podemos ter região, produto, trimestre, canal, cliente e muitos outros. CUBE não se limita a um cubo geométrico. Acima de três dimensões, precisamos abstrair com recortes, projeções ou tabelas, pois não conseguimos representar todos os eixos espaciais diretamente neste desenho 3D.

Com n dimensões independentes, CUBE gera 2n conjuntos de agrupamento e ROLLUP gera n + 1 níveis na ordem escolhida. Aqui: cubo 3D → plano 2D → linha 1D → total 0D.
